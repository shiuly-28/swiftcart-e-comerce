What is the use of the map() function in JavaScript? How is it different from forEach()?
Ans:Use map() when you need a new array, forEach() when you just want to perform actions on each element.
What is the difference between == and ===?
Ans:Always use === to avoid unexpected type coercion. Use == only if you intentionally want type conversion.
